# Vishesh Dixit — Developer Portfolio

A modern, responsive, and interactive personal developer portfolio built
with **HTML5, CSS3, and Vanilla JavaScript**.

This portfolio is designed to showcase my skills, projects, education,
experience, career goals, and contact information in a clean and
professional interface.

## 👨‍💻 About the Project

This project is my personal developer portfolio website.

The main goal of this portfolio is to create a professional online
presence where recruiters, hiring managers, and other developers can
quickly understand my technical skills, projects, education, and
development interests.

The entire website is built using frontend technologies without requiring
a backend server or database.

## ✨ Features

### 🌓 Dark / Light Mode

Users can switch between dark and light themes.

The selected theme is stored using browser `localStorage`, so the
preference can remain available after refreshing the page.

---

### ⌨️ Typing Animation

The hero section contains a dynamic typing animation that displays
different professional roles such as:

- Software Developer
- Web Developer
- Java Developer
- Frontend Developer
- Problem Solver

---

### 📱 Responsive Navigation

The navigation automatically adapts to smaller screen sizes.

On mobile devices, a hamburger menu is displayed for easy navigation.

---

### 🎯 Project Filtering

Projects can be filtered according to their technology/category.

Available filters include:

- All
- Java
- Web
- JavaScript

---

### ✨ Scroll Reveal Animation

Different sections and project cards appear with smooth animations
as the user scrolls through the website.

This is implemented using JavaScript's `IntersectionObserver`.

---

### 📩 Contact Form Validation

The contact form validates:

- Name
- Email
- Subject
- Message

The current version performs **frontend validation only**.

No backend or database is connected to the form yet.

---

### 🔝 Back to Top

A back-to-top button appears after scrolling down the page and allows
users to quickly return to the top.

---

### 📅 Dynamic Copyright Year

The footer year is automatically generated using JavaScript, so it does
not need to be manually updated every year.
